# Emotion Prediction

A deep learning web application that predicts emotions from text using a **BiGRU neural network**.

### Features

* 6 emotion classes: sadness, joy, love, anger, fear, surprise
* Text preprocessing and tokenization
* Sequence padding for model input
* Confidence scores for predictions
* FastAPI REST API
* Interactive web interface
* Deployed on Render

### Tech Stack

Python · TensorFlow/Keras · FastAPI · NumPy · Pydantic · HTML/CSS/JavaScript
